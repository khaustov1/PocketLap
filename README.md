# PocketLap OS images

This repository hosts downloadable OS images for PocketLap in [Releases](https://github.com/khaustov1/PocketLap/releases).

The ARM64 image includes Ubuntu 26.04 and KDE Plasma, with Breeze Dark as the default theme. Each release provides an OS archive and its SHA-256 checksum.

PocketLap application source code is not published in this repository.
